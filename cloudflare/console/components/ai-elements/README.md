# Vercel AI Elements

`conversation.tsx` and `message.tsx` adapt the Conversation, ConversationContent,
ConversationScrollButton, Message and MessageContent components published at
https://elements.ai-sdk.dev/api/registry/conversation and
https://elements.ai-sdk.dev/api/registry/message, retrieved October 7, 2026.

Copyright Vercel, Inc. Licensed under Apache 2.0; see LICENSE in this directory.
The unused download, branching, action and Streamdown components are omitted.
Utility classes are mapped to this console's CSS, the scroll button uses native
HTML, and the UIMessage role type is local. Markdown is rendered by react-markdown.
